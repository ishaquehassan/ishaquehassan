### `> whoami`

**Flutter Framework Contributor from Pakistan, listed in Flutter's [Authors list](https://github.com/flutter/flutter/blob/master/AUTHORS#L150).** 13+ years in software engineering, based in Karachi. Currently **Engineering Manager** at [DigitalHire](https://digitalhire.ai), building the world's first integrated talent engine.

I contribute directly to the **Flutter ecosystem**. **15 pull requests merged into the official Flutter org repos** (12 in [flutter](https://github.com/flutter/flutter), 3 in [devtools](https://github.com/flutter/devtools)) with 5 more in active review. Two of them were called out by name in the official **[Flutter 3.50 release notes](https://flutter.dev/blog/whats-new-in-flutter-3-50)**. My work spans painting APIs, focus and keyboard navigation, animation APIs, `flutter_tools`, DevTools internals, and documentation.

Instructor of the **Flutter Urdu course** officially listed on [docs.flutter.dev/resources/courses](https://docs.flutter.dev/resources/courses#urdu). GDG Kolachi Mentor. 50+ production apps shipped.
